      A note on optical telegraphs, and what is invented here

      What really happened. The Chappe brothers' optical telegraph sent its first message on the Paris–Lille line in August 1794: a chain of towers within sight of one another, each topped by a long rotating bar, the regulator, with a smaller rotating arm, an indicator, at each end. Operators read the neighbouring tower through a telescope and set their own mechanism to the same position, so a signal passed from tower to tower. More lines followed, and by the middle of the nineteenth century optical telegraphs reached across Western Europe and North Africa. France began replacing its optical system with the electric telegraph in 1846, and the Chappe lines fell out of use around 1852. The meaning lay in a codebook: in the Chappe system each of 92 signal positions stood for a page of a code book, and, according to one history, coding and decoding were done only at the end and divisional stations, while the operators between simply repeated each signal without knowing the code.

      What is invented here. This tower, its operator and its messages are fiction. The five-lamp training panel is invented; Chappe stations did not signal in binary lamps. The two-arm code in Silver is an original, simplified teaching code with four positions per arm; it is not the historical Chappe code, in which each indicator had seven positions and the signals pointed to pages and lines of a code book.

      The modern lesson. Gold's check bits are a twentieth-century idea, anachronistic in an 1830s tower: Richard Hamming of Bell Telephone Laboratories published single-error-correcting codes in 1950, and the seven-bit code used here (four data bits, three check bits) is his. It corrects any one flipped bit; it cannot correct two, and with two flips it can point to the wrong position. (An eighth, overall parity bit, the extended “SECDED” code, can detect two errors; it is not used here.) The game assumes exactly one bit was flipped.

Turing Award, Richard W. Hamming; R. W. Hamming, “Error Detecting and Error Correcting Codes”, Bell System Technical Journal 29 (April 1950). Full addresses are in the game's documentation.

## Story premise

After an icequake, a survivor must investigate knocks from a supposedly flooded compartment, determine whether the ORCHARD system is telling the truth, and decide how to use a final transmission.

## Playable features

Branching survival decisions; simulated oxygen reserve; tap-code visualization; seven station-log discoveries; evidence-dependent endings; back, restart, browser-local saves and ending discovery.

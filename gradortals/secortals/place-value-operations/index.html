Word help

Loose key
One single key. Worth 1. It hangs on the Ones hook.
Ring
Ten keys tied together. Worth 10. It hangs on the Tens hook.
Hoop
Ten rings tied together. Worth 100. It hangs on the Hundreds hook.
Tie
Make a bigger bundle from ten smaller ones. The number of keys stays the same.
Untie
Open one bundle into ten smaller ones. The number of keys stays the same.
Lend
Give keys to a neighbor. Those keys leave, so the total goes down.
Receive
Keys come to Nan. The total goes up.
Jam
A hook window can only show one digit, 0 to 9. Ten or more on one hook jams it.
Zero
“No bundles on this hook.” A zero still holds its place: 107 is not 17.
